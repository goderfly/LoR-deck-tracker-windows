# Архитектура LoR Deck Tracker

## Обзор архитектуры

Архитектура проекта спроектирована по модульному принципу без циклических зависимостей:

```
[ Legends of Runeterra Game Client ] (:21337)
                │ HTTP REST
                ▼
   [ lor.tracker_engine.LoRClient ]
                │ Snapshot State
                ▼
      [ lor.manager.OverlayManager ] ◄──► [ lor.card_db.CardDatabase ]
                │                                    │
    ┌───────────┼───────────┐                 [ Riot DataDragon ]
    ▼           ▼           ▼                 (cards_cache_ru.json)
[PlayerPanel] [OpponentPanel] [AdvisorBar]
    │           │           │
    └───────────┼───────────┘
                ▼
       [ lor.preview.CardPreview ]
```

## Ключевые компоненты

1. **`lor.tracker_engine`**:
   - Опрос локального API LoR (`http://127.0.0.1:21337/positional-rectangles`, `/static-decklist`).
   - Постоянное отслеживание по `CardID`: карта сохраняет свой уникальный ID на протяжении всей партии. Даже если карта уничтожена или вернулась в руку, она никогда ошибочно не возвращается в счетчик колоды.
   - Механизм дебаунса (3 секунды) защищает от кратковременных пустых кадров анимации клиента Riot.

2. **`lor.card_db`**:
   - Автономная база данных карт с офлайн-кэшем 2512 карт.
   - Индексация ключевых слов, фракций, скорости заклинаний и редкостей.
   - Фоновая асинхронная загрузка изображений карт и значков регионов.

3. **`lor.advisor_engine`**:
   - Динамический каталог тактических заклинаний (Fast/Burst).
   - Фильтрация по открытым регионам оппонента и расчету доступной маны (текущая мана + банк заклинаний).

4. **`lor.win32ext`**:
   - Реализация расширенных стилей Win32:
     - `WS_EX_NOACTIVATE`: клики по оверлею не отнимают фокус у полноэкранного окна игры.
     - `WS_EX_TRANSPARENT`: поддержка сквозных кликов (click-through).
     - `WS_EX_APPWINDOW`: отображение в панели задач Windows с отдельной кнопкой и иконкой.
     - `HWND_TOPMOST`: гарантированное положение поверх DirectX окна игры.
