# Сборка Legends of Runeterra Deck Tracker

Данный документ описывает процесс сборки автономного исполняемого файла (`.exe`) для Windows.

---

## 📋 Требования к окружению

1. **Операционная система**: Windows 10 или Windows 11 (64-bit).
2. **Python**: версия 3.10 – 3.13 (64-bit).
3. **Установленные зависимости**:
   - `PyQt6` (графический интерфейс и рендеринг HUD)
   - `requests` (сетевые запросы к клиенту LoR и Riot DataDragon)
   - `pywin32` (низкоуровневые API Windows: click-through, topmost, taskbar)
   - `Pillow` (обработка и кэширование изображений карт)
   - `pyinstaller` (компилятор в автономный .exe)

---

## 🚀 Быстрая сборка в 1 клик

В корне проекта находится командный файл для Windows:

```cmd
build.bat
```

Скрипт автоматически:
1. Проверит наличие Python и необходимых библиотек.
2. Очистит кэши предыдущих сборок (`build/`, `*.pyc`).
3. Сформирует метаданные версии Windows (ProductVersion 1.0.0.0, описание, копирайт).
4. Запустит компиляцию PyInstaller со всеми вшитыми ресурсами (база карт, иконка, регионы).
5. Разместит готовый `.exe` в директории `release/LoRDeckTracker.exe`.

---

## 🛠️ Сборка вручную через Python

Вы также можете запустить скрипт сборки напрямую через Python:

```bash
# 1. Установка зависимостей (в виртуальном окружении или глобально)
python -m pip install -r requirements.txt

# 2. Запуск сборщика
python scripts/build_exe.py
```

Опциональные флаги сборщика:
- `--clean`: Полная очистка временных файлов перед компиляцией.
- `--zip`: Автоматическая упаковка собранного приложения в `release/LoRDeckTracker-v1.0.0-windows-x64.zip`.
- `--debug`: Сборка с открытым терминалом консоли (для отладки).

---

## 📂 Структура артефактов сборки

После завершения компиляции:
- `release/LoRDeckTracker.exe` — готовый к распространению исполняемый файл.
- `release/LoRDeckTracker-v1.0.0-windows-x64.zip` — готовый архив для релизов на GitHub / веб-сайте.
- `build/` — временные файлы сборки PyInstaller (игнорируются git).
- `dist/` — стандартная выходная папка PyInstaller.

> [!NOTE]
> Скомпилированный `LoRDeckTracker.exe` является **полностью автономным** (single-file bundle). Он содержит внутри все 2512 карт на русском языке, иконку приложения и все значки регионов. Пользователю не требуется устанавливать Python или вспомогательные файлы.
